# Neovim Shortcuts

`<Leader>` = `\`

## 基本操作

| キー | 動作 |
|------|------|
| `<Leader>w` | 保存 |
| `<Leader>q` | 閉じる |
| `<Leader>wq` | 保存して閉じる |
| `Ctrl+/` | コメントトグル |

## ウィンドウ

| キー | 動作 |
|------|------|
| `<Leader>h` | 左のウィンドウへ |
| `<Leader>j` | 下のウィンドウへ |
| `<Leader>k` | 上のウィンドウへ |
| `<Leader>l` | 右のウィンドウへ |
| `<Leader>s` | 水平分割 |
| `<Leader>v` | 垂直分割 |

## ファイルエクスプローラー (nvim-tree)

| キー | 動作 |
|------|------|
| `Ctrl+n` | ツリー開閉 |
| `<Leader>e` | ツリーにフォーカス |

## ファイル検索 (Telescope)

| キー | 動作 |
|------|------|
| `<Leader>ff` | ファイル検索 |
| `<Leader>fg` | 文字列検索 (grep) |
| `<Leader>fb` | バッファ一覧 |
| `<Leader>fh` | ヘルプ検索 |
| `<Leader>fr` | 最近開いたファイル |
| `<Leader>fc` | カーソル下の文字列を検索 |

### Telescope内操作

| キー | 動作 |
|------|------|
| `Ctrl+j` | 次の候補 |
| `Ctrl+k` | 前の候補 |
| `Ctrl+q` | 選択をQuickfixへ送る |
| `Esc` | 閉じる |

## LSP

| キー | 動作 |
|------|------|
| `gd` | 定義へジャンプ |
| `gD` | 宣言へジャンプ |
| `gi` | 実装へジャンプ |
| `gr` | 参照一覧 |
| `K` | ホバー情報 |
| `Ctrl+k` | シグネチャヘルプ |
| `<Leader>rn` | リネーム |
| `<Leader>ca` | コードアクション |
| `<Leader>d` | 診断表示 |

## インサートモード

| キー | 動作 |
|------|------|
| `Ctrl+h` | 左へ移動 |
| `Ctrl+j` | 下へ移動 |
| `Ctrl+k` | 上へ移動 |
| `Ctrl+l` | 右へ移動 |

## その他

| キー | 動作 |
|------|------|
| `<Leader>tt` | ターミナルを開く |
