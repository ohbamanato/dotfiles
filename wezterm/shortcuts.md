# WezTerm ショートカット一覧

**Leader キー: `Ctrl + q`** (2秒間有効)

## Workspace

| キー | 説明 |
|------|------|
| `Leader` + `w` | Workspace一覧を表示・切り替え |
| `Leader` + `$` | Workspace名を変更 |
| `Leader` + `Shift` + `W` | 新規Workspaceを作成 |

## Tab

| キー | 説明 |
|------|------|
| `Cmd` + `t` | 新規タブを作成 |
| `Cmd` + `w` | タブを閉じる |
| `Ctrl` + `Tab` | 次のタブへ移動 |
| `Ctrl` + `Shift` + `Tab` | 前のタブへ移動 |
| `Leader` + `{` | タブを左に移動 |
| `Leader` + `}` | タブを右に移動 |
| `Cmd` + `1~8` | タブ1~8に切り替え |
| `Cmd` + `9` | 最後のタブに切り替え |

## Pane

| キー | 説明 |
|------|------|
| `Leader` + `d` | 縦分割 |
| `Leader` + `r` | 横分割 |
| `Leader` + `x` | Paneを閉じる |
| `Leader` + `h` | 左のPaneへ移動 |
| `Leader` + `l` | 右のPaneへ移動 |
| `Leader` + `k` | 上のPaneへ移動 |
| `Leader` + `j` | 下のPaneへ移動 |
| `Leader` + `z` | Paneのズーム切り替え |
| `Ctrl` + `Shift` + `[` | Pane選択モード |
| `Leader` + `a` | Pane移動モード (1秒間有効) |
| `Leader` + `s` | Paneサイズ調整モード |

### Paneサイズ調整モード (`Leader` + `s`)

| キー | 説明 |
|------|------|
| `h` | 左に縮小 |
| `l` | 右に拡大 |
| `k` | 上に縮小 |
| `j` | 下に拡大 |
| `Enter` | モード終了 |

## コピー/ペースト

| キー | 説明 |
|------|------|
| `Cmd` + `c` | コピー |
| `Cmd` + `v` | ペースト |
| `Leader` + `[` | コピーモードに入る |

### コピーモード (`Leader` + `[`)

#### 移動

| キー | 説明 |
|------|------|
| `h` / `j` / `k` / `l` | 左/下/上/右に移動 |
| `w` | 次の単語へ |
| `b` | 前の単語へ |
| `e` | 単語の末尾へ |
| `0` | 行頭へ |
| `^` | 行頭(空白除く)へ |
| `$` | 行末へ |
| `g` | バッファの先頭へ |
| `G` | バッファの末尾へ |
| `H` | 画面上部へ |
| `M` | 画面中央へ |
| `L` | 画面下部へ |

#### ジャンプ

| キー | 説明 |
|------|------|
| `f` + 文字 | 指定文字へジャンプ |
| `F` + 文字 | 指定文字へ逆方向ジャンプ |
| `t` + 文字 | 指定文字の手前へジャンプ |
| `T` + 文字 | 指定文字の手前へ逆方向ジャンプ |
| `;` | 直前のジャンプを繰り返す |

#### スクロール

| キー | 説明 |
|------|------|
| `Ctrl` + `f` | 1ページ下へ |
| `Ctrl` + `b` | 1ページ上へ |
| `Ctrl` + `d` | 半ページ下へ |
| `Ctrl` + `u` | 半ページ上へ |

#### 選択

| キー | 説明 |
|------|------|
| `v` | 文字選択モード |
| `V` | 行選択モード |
| `Ctrl` + `v` | 矩形選択モード |
| `o` | 選択範囲の反対側へ |
| `O` | 選択範囲の反対側へ(水平) |

#### コピー/終了

| キー | 説明 |
|------|------|
| `y` | コピー |
| `Enter` | コピーしてモード終了 |
| `Escape` / `q` / `Ctrl` + `c` | モード終了 |

## その他

| キー | 説明 |
|------|------|
| `Cmd` + `p` | コマンドパレット |
| `Ctrl` + `Shift` + `p` | コマンドパレット |
| `Ctrl` + `Shift` + `r` | 設定を再読み込み |
| `Alt` + `Enter` | フルスクリーン切り替え |
| `Ctrl` + `+` | フォントサイズ拡大 |
| `Ctrl` + `-` | フォントサイズ縮小 |
| `Ctrl` + `0` | フォントサイズリセット |
